WordPress Go

WordPress, rewritten in Go. Version {{.Version}} on {{.Go}}.
What’s New

One binary

The whole of WordPress — admin, REST API, themes, media, cron — compiled into a single Go binary with its assets embedded. No PHP, no extensions, no FPM pool.

PostgreSQL with real types

Posts, terms, users and comments live in typed tables with JSONB where flexibility helps. Full-text search uses a generated tsvector.

Gotenberg

The block editor you know, running on WordPress Go’s REST API. Prefer the classic screen? The Classic Editor plugin is built in.

Sandboxed plugins

Plugins are signed WebAssembly modules. They ask for permissions when you activate them and can’t touch anything else; a misbehaving plugin is stopped, not your site.

WPGo Cache

A LiteSpeed-style page cache built in: tag-based purges, a crawler and page optimizations, behind any web server.

No Gravatar

Profile pictures come from your own Media Library. Nothing about your visitors is sent to a third party to draw an avatar.

{{if .Golementor}}

Golementor

A visual page and theme builder: design pages, headers, footers and archives, then save the result as a theme.

{{end}}

Four classic themes

Twenty Sixteen, Twenty Seventeen, Twenty Twenty and Twenty Twenty-One ship with their original styles and work with the Customizer.

Contributors

Lead Developer: Bora Ata Türkoğlu

WordPress Go builds on WordPress by the WordPress contributors, released under the GPL. Third-party attributions are listed in the NOTICE file.
